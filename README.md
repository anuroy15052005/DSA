# DSA

A collection of Java solutions for common Data Structures and Algorithms problems.

## Topics

- Longest Common Subsequence
- One-dimensional Dynamic Programming
- Mathematics
- Patterns
- Recursion
- Sliding Window
- Two Pointers

## Run a Java file

```bash
javac path/to/file.java
java -cp path/to ClassName
```

Replace `ClassName` with the public class name in the selected Java file.
